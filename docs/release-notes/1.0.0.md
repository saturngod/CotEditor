# Version 1.0.0

17 Nov 2026

- Syntax highlighting for TSX, JSX, Vue, and Blade files.
- Split view: edit two files side by side in the same window.
- Multiple tabs in folder windows.
- Folder search skips files listed in `.gitignore`.
- The file browser shows hidden files by default.
- Quick Open (⌘P) to jump to any file in the folder.
- Command Palette (⇧⌘P) to run any menu command by name.
- Go to Symbol (⇧⌘O) to jump to a heading, function, or other symbol in the current file.
- The sidebar colors follow the current editor theme.
- Automatic updates. Choose YayEditor > Check for Updates… to check now.
